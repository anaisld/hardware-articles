# Circuit Notes — Hardware Engineering Articles

This folder contains a complete static website with two technical articles and a homepage. Images are embedded inside the article HTML files, so no extra image uploads are needed.

## Publish for free with GitHub Pages

1. Sign in to GitHub and create a **public** repository named `hardware-articles` (or another name you prefer).
2. Select **Add file → Upload files** and upload **the three HTML files inside this folder** (`index.html`, `psi5.html`, `photovoltaic.html`) to the root of the repository. Commit the changes.
3. Open **Settings → Pages** in that repository.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then click **Save**.
5. Once GitHub finishes deploying, your site will be available at `https://YOUR-USERNAME.github.io/hardware-articles/` (if you used that repository name). It may take a few minutes to appear.

You can preview locally by double-clicking `index.html`. To add a new article later, upload its HTML and add a link on the homepage.

The two articles are based on the original laboratory reports and include their original technical figures. Before making the site public, review the article authorship and ensure you have permission to publish the co-authored material.
