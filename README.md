# Engineering Portfolio — GitHub Pages

This release contains the four original articles and the seven **individually reviewed and approved** articles.

## Publish
1. Extract this ZIP.
2. Upload **index.html**, all 11 project HTML files, and the **assets/** folder to the root of your GitHub Pages repository. Keep the folder structure unchanged.
3. Commit to the `main` branch.
4. In GitHub Settings → Pages, use Deploy from a branch → `main` / `(root)` (or keep your existing deployment setup).
5. Wait for the Pages deployment, then refresh the website with Ctrl+F5.

The seven newly approved HTML articles embed their original illustrations directly, so no separate image files are needed for them. The original four articles and the homepage still use the assets/ folder.
